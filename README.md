# 📚 Student Record Management System (C)

A beginner-friendly **Student Record Management System** developed in **C language** using structures and file handling.

This project demonstrates core C programming concepts and is ideal for BCA students and beginners.

---

## ✨ Features
- Add student records
- View all students
- Search student by roll number
- Delete student record
- File handling using `.dat` file

---

## 🛠 Concepts Used
- Structures
- File handling (`fopen`, `fread`, `fwrite`)
- Functions
- Loops & switch-case
- Basic CRUD operations
